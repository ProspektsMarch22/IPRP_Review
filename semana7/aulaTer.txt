Listas

> Listas por compreensão
--> Tentar entender o que é e como fazer, dando uma olhada em possíveis exemplos para list compreheension

[1, [2, 3, [4]], [5, 6]]

É possível fazer cópias de listas com slices:

vogais = [1, 2, 3]
copia = vogais[:]

Melhor usar copia profunda:

import copy
vogais = [1, 2, 3, [4, 5], 6]
copia = copy.deepcopy(vogais)

referência x valor

tpc 6.1 6.2 6.3 6.4 6.6
